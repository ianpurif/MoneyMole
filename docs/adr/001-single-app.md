# Single application and local trust boundary

Date: 2026-09-26. Status: Accepted for preparation.

Use one Next.js App Router application and browser-side wallet/private-state adapters. Start without a database, custodial signer or extra backend. This minimizes components with access to secrets. A backend requires evidence of necessity and a privacy review; it cannot receive plaintext openings.

Revisit only with new observed evidence; record the affected interfaces, tests and requirement states.
